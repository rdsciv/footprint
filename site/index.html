Install

Python 3, stdlib only. Statusline never networks. Live grid: FOOTPRINT_SITE + Electricity Maps token, then refresh.

git clone https://github.com/rdsciv/footprint && cd footprint
pip install .

# statusline — .claude/settings.json
{ "statusLine": { "type": "command", "command": "python3 /path/to/footprint/footprint_statusline.py" } }

python3 -m modelfootprint report
python3 -m modelfootprint whatif opus 500k

Optional live grid: FOOTPRINT_SITE=virginia and a free Electricity Maps token. Deep dives live in the repo.
