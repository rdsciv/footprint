Estimate a workload

Energy, water and carbon for a token mix you choose. Every figure is a scenario envelope — every factor at its low or high bound at once — not a confidence interval.

When you prompt: the duck curve

The same workload carries very different carbon depending on the hour, because the grid’s marginal generator changes. Hover or tap the curve — stylized from documented CAISO anchors (≈0 g midday surplus, 500–630 g evening ramp).

Which model: energy per tier

Energy for the workload configured above, re-priced on each model tier. Whiskers are the propagated low–high bounds. All tier coefficients are MODELED — 2–3× bands.

What you could have saved

Modeled scenarios on the same token mix. Not a promise you can force provider routing or always defer interactive work.

Receipts

Measured anchors stay in their own units. They are not substituted into the per-token math, because each disclosure’s workload shape differs from an arbitrary session.

  • 0.24 Wh · 0.26 mL · 0.03 gCO2e Google, median Gemini Apps text prompt, full-stack (arXiv:2508.15734). Carbon figure is market-based — not comparable to this tool’s location-based default.

  • ~0.3–0.34 Wh / typical query Epoch AI modeled ChatGPT-class estimate and Altman’s public figure. A sanity band, not a coefficient.

Install

Python 3, stdlib only. The statusline never touches the network; live grid and weather refresh into an hourly cache.

git clone https://github.com/rdsciv/footprint && cd footprint
pip install .

# statusline — .claude/settings.json
{ "statusLine": { "type": "command", "command": "python3 /path/to/footprint/footprint_statusline.py" } }

python3 -m modelfootprint report
python3 -m modelfootprint whatif opus 500k

Optional live grid: FOOTPRINT_SITE=virginia and a free Electricity Maps token. Deep dives live in the repo.
